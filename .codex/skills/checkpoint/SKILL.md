# Checkpoint harness work

Write a concise `HANDOFF.md` at the repository root containing:

- Goal and current status.
- Completed, verified work.
- Immediate next step and exact next command.
- Decisions and unresolved questions.
- Files currently in flight.
- Known failures or checks not run.

Read current Git status and the active task context first. Keep the handoff to roughly one screen. Do not invent completion or verification evidence.
