## 2. Goal, exclusions, and acceptance outcomes

The original goal below is retained for historical coverage. Continue from the accepted integrated candidate using [Addendum 3](addendum-3/plan-workflow.md). Its full 19-file composition owns the current 21 requirements, mapped launch overrides, repeated source audits, exhaustive Windows matrix, and macOS/Linux native-evidence gap policy; no future work waits for those missing runners. Replace the candidate implementation in `harness-single` with the simplest complete implementation of the normative v2 specification.
