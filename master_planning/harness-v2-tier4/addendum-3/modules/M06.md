## Module contract and selection

| Module type | Decision | Instance IDs | Reason |
|---|---|---|---|
| M06 | SELECTED | MI-NORMAL-INTEGRATE, MI-NORMAL-LIVE-TEST-INTEGRATE, MI-FL2-S1-ADMISSION-INTEGRATE, MI-FL2-S1-PRODUCT-INTEGRATE, MI-FL2-S1-ASSET-INTEGRATE, MI-FL2-S1-INTEGRATION-INTEGRATE, MI-FL2-S2-INTEGRATION-RECONCILE, MI-FL2-S1-ASSURANCE-INTEGRATE, MI-FL2-S1-LIVE-INTEGRATE | Normal branches need one join; STEP-006 needs one exact test-only join onto the accepted STEP-005 coordinate; every Series 1 correction needs separate integration/readback and STEP-004 Series 2 needs affected-only coordinate reconciliation |

## Public interface and compatibility boundary

Consumes exact accepted revisions and verdicts, a base, destination, order, conflict owner, check selection, retention rule, and user-authorized write authority. Produces one integrated coordinate or exact operation block. Changed input/order/destination/check semantics invalidate the output; internal conflict-free Git mechanics do not.

## Rules, process, recipe actions, and allowed variations

P01, P02, P04, P09, P10, and P13 through P15 apply. ROOT owns every semantic or conflict decision. INTEGRATOR performs only the complete declared mechanics. Promotion is explicitly omitted; retirement remains ROOT-owned.

| 1 | M06-A1 | Revalidate the two accepted revisions and their M05 verdicts before mutation | Exact input identities from JOIN-001 | ROOT |
| 2 | M06-A2 | Verify WT-INTEGRATE and destination cleanliness and retain the admitted rollback base | Local integration coordinate only | ROOT |

| 8 | M06-A8 | Leave retirement to ROOT and retire only clean terminal unclaimed allocations | No worker-side deletion | ROOT |

The only integration writer owns one linked worktree. No product/asset writer or other integrator may mutate its branch.

#### Resources and side effects

Creates only the authorized local integration coordinate and check caches. No remote push, publication, promotion, or deletion occurs.

#### Checks and acceptance

Revalidate inputs, inspect combined diff/status, run CHECK-INTEGRATION, and read back the coordinate. ROOT decides the operation gate.

#### Failure and exception routes

Ambiguous/content conflict returns to ROOT before mutation continues. Product failure goes to M05. Operation/support failure never reopens accepted inputs. No exception exists.

Input acceptance stays valid while exact revisions remain unchanged. Rerun only the affected integration action/check after an operation correction.

One ordered join. Success activates STEP-005; unresolved operation remains visible. No promotion runs and ROOT later retires state.

#### Cost and critical-path effect

One worker launch and one serial join after PG-001; M07 owns broad checks on the resulting coordinate.
