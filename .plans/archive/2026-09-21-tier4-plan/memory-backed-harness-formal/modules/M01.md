## Public interface and compatibility boundary

missing downstream predicate + authority -> verified SATISFIED / exact INCOMPLETE; never product implementation. Concrete values and return targets belong to the owning step's configured instance. Private changes do not alter public semantics; update actual consumers for a real contract change.

## Rules, process, recipe actions, and allowed variations

P01–P15 own shared rules. Semantic choices in recipe verbs remain ROOT decisions; test_root only authors declared lane-local contracts. Workers mechanically execute supplied choices and return any missing meaning. Reviewer findings remain open within assigned boundaries. Each governing card cites all actions; member cards cite only their ordered subset. Parameters may select bounded source/test paths and optional profiles, never weaken acceptance or change authority.

- `SATISFIED` unlocks only consumers that declare this result as an input.
- Failed prerequisite setup returns to the same M01 owner only when the failure is correctable within
  the original card; otherwise it is `INCOMPLETE`.
- Discovery of product work exits to plan amendment; M01 cannot absorb it.
