Express one required workflow capability that cannot be composed from M01-M09. Extension is a last
resort, not permission to create a project-specific duplicate of an existing module or policy.

## Public interface and compatibility boundary

demonstrated unexpressible workflow need -> separately approved extension; omitted because M01–M09 suffice. Concrete values and return targets belong to the owning step's configured instance. Private changes do not alter public semantics; update actual consumers for a real contract change.
