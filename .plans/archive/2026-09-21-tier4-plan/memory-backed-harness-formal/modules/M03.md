## Public interface and compatibility boundary

## Rules, process, recipe actions, and allowed variations

P01–P15 own shared rules. Semantic choices in recipe verbs remain ROOT decisions; test_root only authors declared lane-local contracts. Workers mechanically execute supplied choices and return any missing meaning. Reviewer findings remain open within assigned boundaries. Each governing card cites all actions; member cards cite only their ordered subset. Parameters may select bounded source/test paths and optional profiles, never weaken acceptance or change authority.
