# Archive

This directory holds completed or superseded material without discarding its evidence.

- `firmware-v2-campaign/` contains the closed Plan 2/Firmware campaign: its plans, historical
  handoffs, campaign-only Firmware documentation, session analysis, and `campaign-logs/` from the
  retired top-level Firmware validation runtime.
- `harness-v1/` contains the older topology-design reference prompts.

Active compatibility work remains outside this directory in `plans/compatibility-testing/`,
`active_docs/`, and the restored `harness-single-worktrees/{compat-test,qwencode-test}` worktrees.
Historical evidence intentionally retains some original path strings so that recorded results remain
auditable; those strings are not live repository references.
